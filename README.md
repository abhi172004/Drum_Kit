# 🥋 Drum Kit Website

A simple and interactive Drum Kit web app built using HTML, CSS, and JavaScript. Users can play drum sounds either by clicking on drum buttons or pressing the corresponding keys on their keyboard.

[Live Preview](#)  🔗 https://abhi172004.github.io/Drum_Kit/

```

└── sounds/            # Sound files for each drum
```

## 🧠 How It Works

Each button on the webpage corresponds to a drum sound. JavaScript listens for either a `click` event or a `keydown` event and then:

* Plays the appropriate `.mp3` file.
* Triggers a short animation on the button.
